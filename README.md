### 🚀 Featured Project: Saiko-Trilingual-LSTM
A custom Neural Machine Translation system for **Afaan Oromoo ↔ Amharic ↔ English**.

*   **Model:** Custom Seq2Seq (Bi-LSTM + Bahdanau Attention) built in PyTorch.
*   **Deployment:** Live on Streamlit Cloud with a Hybrid Translation Memory.
